# DesignsBridge Landing Page

A responsive construction and interior design landing page created as a frontend development practice project. DesignsBridge showcases services, projects, testimonials, team members, and contact sections through a clean and modern website layout.

## Features

- Responsive navigation bar
- Hero section with image slider
- Call-to-action sections
- About section
- Construction and interior design services
- Project portfolio/gallery
- Client testimonials
- Expert team section
- Contact section and form
- Responsive design for desktop, tablet, and mobile
- Hover effects and interactive elements

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- JavaScript
- Google Fonts

## Project Purpose

This project was created to practice and improve my frontend development skills, including responsive layouts, website structure, styling, Bootstrap components, and creating modern landing pages.

The website was developed and customized as part of my frontend development practice.

## Responsive Design

The website is designed to work across different screen sizes, including:

- Desktop
- Tablet
- Mobile
